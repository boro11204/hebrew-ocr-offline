Hebrew OCR Offline

Reads printed seforim into text, in square script and Rashi script, and proofreads a typed text against the original scan. No AI, no API key, no internet once installed. It runs on your own computer.

Download (zip) View on GitHub OCR in your browser (no install)

What it is

  • OCR: turns a scan (PDF or image) into Hebrew text. Square script, Rashi script, or Auto (tries both, line by line). Handles two-column pages.
  • Proofreader: compares a typed text (.txt, .docx or .pdf) with the scan and marks the words that differ, in an HTML report and a Word file.
  • Models: Tesseract models fine-tuned on real printed lines from the Vilna Shas and a Prague 1815 print.
  • Written in Python (hebocr). Code under the Apache License 2.0.

Prefer not to install anything? The OCR page on this site runs the same trained models right in your browser, with no AI and no API key.

Install

You need Python 3.9 or newer and Tesseract 5.

# Ubuntu / Debian
sudo apt-get install tesseract-ocr
# macOS
brew install tesseract
# Windows: install Tesseract from https://github.com/UB-Mannheim/tesseract/wiki

pip install -r requirements.txt

If the model files are missing:

curl -L -o models/heb_rashi4.traineddata https://hebrew-ocr.sites.tab.bot/tessdata/heb_rashi4.traineddata
curl -L -o models/heb_rashi7.traineddata https://hebrew-ocr.sites.tab.bot/tessdata/heb_rashi7.traineddata
curl -L -o models/heb_rashi6.traineddata https://hebrew-ocr.sites.tab.bot/tessdata/heb_rashi6.traineddata
curl -L -o models/heb4.traineddata https://hebrew-ocr.sites.tab.bot/tessdata/heb4.traineddata

Run it

Run these from the repo folder (the unzipped hebrew-ocr-offline-main folder).

Read a scan into text

python3 -m hebocr ocr page.jpg --script rashi --out page.txt
python3 -m hebocr ocr book.pdf --pages 1-10 --script square --layout columns --out book.txt
  • --script: rashi, square, or auto (tries both, line by line).
  • --layout: columns for two-column pages, block for one column, auto to let Tesseract decide.
  • --rashi-model: which Rashi model to use (default heb_rashi7; heb_rashi6 and older still work). Same as setting HEBOCR_RASHI.
  • --correct: turns on the word-list spelling fix. It helps a little on square script and does about nothing on Rashi, so it is off by default.

Proofread a typed text against the scan

python3 -m hebocr proofread typed.docx scan.pdf --pages 15-30 --out report

The typed file can be .txt, .docx or .pdf. This writes:

  • report.html: the typed text with colors. Click a mark to see the scan line it came from. Yellow changed word, more sure · Orange changed word, worth checking · Red crossed out typed words not in the scan · [חסר: …] words in the scan missing from the typed text
  • report.docx: the same marks in Word.
  • report.json: every flag with its confidence (0 to 1).

The proofreader also takes --rashi-model. Use --sure and --check to change how many flags you see.

New in v8: heb_rashi7 Nov 10, 2026

heb_rashi7 is heb_rashi6 fine-tuned on 24,013 new Vilna Shas Rashi and Tosafot lines (310 pages of the 1882 and 1925 Romm printings, 31 tractates), labelled from Sefaria and checked line by line. Test pages were kept out of training. It is now the default for the website and the command line.
