Train examples from a sefer page

Choose one image page (JPG, PNG, WEBP). It is read in this browser using the repository’s bundled Tesseract models. Crops are shown only when conservative whitespace segmentation yields exactly one region per recognized Hebrew letter. Segmentation can miss joined letters or split dots; inspect every crop. Word confidence is a rough prioritization signal, not letter-level confidence.

Page images stay on this device. PDF is not supported here; render the page to an image first.

Print profile stored on this device

A profile is private to this browser/device unless you export it. Profile examples are confirmed letter labels and compact binary glyph signatures.

Review crops and confirm labels

Cards are ordered from lower word confidence first, with known look-alike pairs surfaced early. The model has no per-letter confidence output; this ordering never claims it knows which glyph is wrong. Choose or type the letter you can verify from the page, then confirm. Confirmed examples can seed cautious, local-only suggestions on another page in this tool.

Upload a page to see reliably segmented character examples. If segmentation is uncertain, no crop is offered.

Profile suggestions on this page

Only select a profile when this page comes from the same print/edition as its examples. Suggestions are generated only if a label has at least three confirmed examples and the nearest template match is both very close and clearly separated from the next label. They are suggestions, not accepted OCR ground truth; no trained model is changed.
